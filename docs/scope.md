# Platform scope

The Paper foundation is a common safety/execution/reporting base, not a Japan-stock-only product boundary.

Current verified capabilities must be distinguished from future target scope. Asset classes should be marked supported only after their broker/data/execution/risk/reporting path has evidence.

Target expansion includes, where technically and legally available through selected brokers/data providers:

- Japan stocks;
- US and other overseas stocks;
- ETFs;
- FX;
- futures;
- options;
- crypto assets.

Do not weaken the common safety guards merely to add another asset class. Each asset class needs explicit capability evidence before being reported as supported.
