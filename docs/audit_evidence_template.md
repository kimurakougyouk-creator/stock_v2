# Final audit evidence checklist

For each completion claim record:

- requirement;
- current-main file/test evidence;
- automated test or CI evidence;
- external evidence, if unavoidable;
- status: complete / partial / blocked / superseded;
- exact blocker or next action when not complete.

Never mark a requirement complete from an implementation file alone when runtime/external evidence is required. Never mark an asset class supported from a capability declaration alone.
